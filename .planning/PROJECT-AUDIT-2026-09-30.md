started-but-unfinished work, disconnected and abandoned code, and stale documentation.

and CI, intake and scripts, marker and static-analysis sweep, git history and orphan scan),

the orchestrator did re-verify by reading the code are marked below.

## Auditor findings, by severity

## High severity (4)

1. **Profiler double-counts numeric sentinel hits on exact string match** — bug, confidence high, area: checks. `dsx/profiler.py:250`  
   Evidence: Lines 250-262: `if stripped in sentinel_set ...: sentinel_hits[stripped] += 1` is immediately followed by `for sent in list(sentinel_set): if math.isclose(float(stripped), float(sent)): sentinel_hits[sent] += 1`. For `--sentinel -1` (sentinel\_set = {'-1'}, line 180) and a cell '-1', both branches fire, so `sentinels_found` reports 2 per occurrence. Only non-canonical forms like '-1.0' should reach the second branch.  
   Action: Make the isclose loop an `else`/`continue` path for values not already matched literally, or dedupe per cell (break after first hit). Add a profiler test asserting one hit per matching cell.
2. **stop-gate blocks forever (ignores stop\_hook\_active and the no-spec early exit) when no python interpreter is found** — bug, confidence high, area: install-hooks-plugin. `hooks/stop-gate:39`  
   Evidence: The interpreter search (lines 33-42) runs `exit 2` before the payload is parsed (lines 47-61) and before the `if [ -z "$specs" ]; then exit 0` no-spec check (line 84). So on a machine without python: (a) a repository with zero ANALYSIS-SPEC files is still blocked from stopping, contradicting the header comment 'No spec, nothing to gate. Safe in a mixed repository' and docs/plugin.md; (b) on the retry Claude Code sets stop\_hook\_active but the script exits 2 again before reading it, so the documented loop-breaker (docs/plugin.md line 50) never fires.  
   Action: Check stop\_hook\_active with a python-free parse (grep/sed) first, or move the python probe after the spec search so a spec-less cwd exits 0; at minimum treat 'no python' as exit 0 with a warning when stop\_hook\_active is set.
